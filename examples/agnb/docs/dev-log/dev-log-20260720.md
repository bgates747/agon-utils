## Project-local emulator profile

- Added `scripts/setup_emulator.py` to create an isolated emulator profile at
  `examples/agnb/.emulator`.
- The profile uses shared symlinks into `~/Agon/fab-agon-emulator` for:
  - the `fab-agon-emulator` executable and `firmware` directory;
  - SD-card `bin` and `mos` directories; and
  - SD-card `firmware.bin` and `MOS.bin` files.
- The profile owns a real, independently editable `sdcard/mystuff` tree and
  `sdcard/autoexec.txt`, allowing multiple project-specific emulator instances
  to run without competing for one startup file.
- Emulator setup copies the canonical `autoexec.txt` only when the local file
  is absent, preserving later project-specific edits.
- Configured the AGNB autoexec working directory as
  `mystuff/agon-utils/examples/agnb/tgt`.
- Changed the emulator deployment step to replace and populate
  `.emulator/sdcard/mystuff/agon-utils/examples/agnb/tgt`.
- Successfully deployed `app.bin` and all 20 RGBA2222 images into that local
  SD-card tree.
- Changed the run step to launch from `.emulator` with a detached
  `subprocess.Popen` session. The build script now returns immediately while
  the emulator continues running.
- Successfully launched the isolated AGNB emulator profile. The emulator stayed
  alive, used the project-local environment, and was subsequently closed
  manually after verification.

## Current operational sequence

1. Run `make_images.py` to generate processed images, RGBA2222 payloads, and
   `images.inc`.
2. Run `do_assembly.py -a` to assemble `app.bin`.
3. Run `do_assembly.py -c` to deploy AGNB's target tree to the local emulator
   profile.
4. Run `do_assembly.py -e` to launch the detached project-local emulator.
