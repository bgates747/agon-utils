# Generic plain-buffer containers and loading

The Author assigned the Golem agent ownership of generic AGNB development,
including formal tasks, documentation and scoped commits/pushes. Generic AGNB
work stays here; Golem-specific package layout/bootstrap/activation stays in
Golem's GOLEM-046. AGNB-001 and this subproject's TODO are the active register.

Provisional0.3 adds explicit-ID BHDR/RAWD/DATA records. RAWD0 means opaque bytes
consolidated into one VDP block, without automatic execution or application
setup. The host writer/reader/manifest CLI is dependency-free. Shared RIFF
helpers preserve image/audio framing. Nine host test methods cover exact bytes,
IDs, alignment, malformed/truncated bounds, build-only paths, output preservation
and aggregate packages larger than0x70000. Existing image writer tests(4) and
manifest tests(1) pass. Compiled agonutils ABI smoke passes.

The local venv had x86_64-only Pillow binaries on the Pi. Reinstalling its same
pinned12.3.0 version for aarch64 restored the existing tests; no dependency
version, system Python or tracked environment file was changed.

The canonical eZ80 API has additive agnb_load_buffers/callback support, using
its existing8KiB transfer window and file/stream/consolidation code. A real
assembler consumer passes. Actual target qualification and applicable human
review remain outstanding; do not interpret host or assembly checks as that
acceptance. Unrelated repository changes are preserved and excluded from AGNB
publication. No physical operations or graphical launches.
