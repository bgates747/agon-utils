AGNB loose assembly routine manifest
====================================

Purpose
-------
Quickly answer "which file defines ROUTINE?" for the loose test harness.
Search this file for the exact label followed by a space or colon.

Scope and conventions
---------------------
- Source snapshot: app.asm and all *.inc files in this directory.
- app.lst is excluded because it is generated from the same source.
- Local labels beginning with @ are excluded.
- Constants, macros, buffers, strings, and other data labels are excluded.
- Named internal flow-entry labels in app.asm are retained and marked [flow].
- Line numbers describe the source at the time this manifest was generated.

Fast reverse lookup
-------------------
The entries above use one routine name per line. From the repository root:

    rg -n '^ROUTINE_NAME[[:space:]]' examples/agnb/images/loose/src/asm/routine-manifest.txt

To verify or locate the definition directly in source:

    rg -n '^ROUTINE_NAME:' examples/agnb/images/loose/src/asm --glob '*.asm' --glob '*.inc'
