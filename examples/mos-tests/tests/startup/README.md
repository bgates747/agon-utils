# Startup qualification

Use human/mos-tests startup-check --output FRESH_DIRECTORY on Linux. The native
primitive checks compile the same SHA/parser headers as AgonDev. Continuation
controls exercise the shared restore_ready implementation against clean and unsafe
slots. Raw-image trials invoke the actual !boot.obey/EXEC script, use external
breakpoints, retrieve card results and SRAM, and call the production reporter.
Fault injection is an explicit hashed fault.bin artifact (zero for normal bundles).
Test output and counter preservation checks stay separate from MOS conformance.
See docs/startup-bundle.md and docs/tasks/MAIN-03/W06/validation.md for limits.
