# Font Editor Tasks

The subproject-root [`TODO.md`](../../TODO.md) is the only authoritative
unfinished-work index. This directory holds task scope, evidence, options,
decisions, and acceptance criteria. Track detailed work in its owning task
document, linked from the root index.

1. Assign each task a stable ID such as `UI-001`, and use that ID as its filename.
2. Mark proposals `DRAFT` until reviewed. Record authorization and decisions in
   the task without treating proposed options as approved implementation.
3. Keep the TODO entry linked to its task. Use explicitly numbered checkboxes
   (`[ ]` pending, `[x]` complete) for task work items and validation criteria.
   Record completion evidence alongside completed items. Mark unselected options
   deferred or not applicable with a reason; do not mark them completed.
4. When work is accepted, rejected, or superseded, record the task ID, evidence,
   and rationale in `docs/development/YYYY-MM-DD.md`, using the local date, then
   remove its TODO entry and update any affected specification. Retain the task
   document as the detail record of the decision.
