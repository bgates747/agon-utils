## Scope and acceptance criteria

1. [x] **Failed-open state preservation.** Decode and prepare a candidate font
   before replacing the current document. Missing, malformed or unsupported
   candidates must preserve current paths, title, control values, edited atlas,
   selected glyph/editor state and saved preferences. Opening must not rewrite
   source metadata or the shared default font configuration. Successful opening
   must still initialize dimensions, refresh the display/editor and update
   recent-file preferences.
   Verified missing source/input, broken TTF with/without sidecar, malformed XML,
   unsupported RGBA2 and invalid color metadata, plus successful PNG/font opens.
2. [x] **Batch/main-document isolation.** Editing batch controls and using Set
   or Cancel must not rerender or change the main document, its controls,
   selection or pixels. Batch values must still change locally and Set must
   persist them. Keep normal main-form rendering controls functional.
   Verified real increment, combobox and color-change paths, Set persistence,
   Cancel/grab release and main-form width changes through its own callback.
3. [x] **Transformed bitmap save/reopen.** Saving the current transformed raster
   as `.font` must write metadata describing that saved bitmap, without applying
   its source transformation again on reopen. Opening the `.font` or its newly
   saved XML sidecar must recover the same monochrome glyph pixels; re-export
   must preserve bytes. Cover offsets, scale, non-byte-aligned widths, edited
   pixels and partial character rows. Saving an export must not replace the
   live source-render settings with incompatible bitmap metadata.
   Verified 5×3, 7×4 and 9×6 cells across 18 glyphs in seven columns, including
   transformed grayscale-to-threshold output and a hand edit. Binary and XML
   opens preserve glyph pixels, and re-export preserves bytes. Live settings
   remain separate from normalized export metadata.
4. [x] **Regression evidence.** Add deterministic tests that fail before the
   fixes. Use synthetic fonts and temporary paths for file/data checks; exercise
   actual Tk controls on a virtual display for GUI state/callback checks. Run
   the existing editor/scaling tests alongside the new regressions. Record
   commands, outcomes, remaining limitations and final implementation boundaries
   in the dated development log and update the relevant behavior specification.
   All five new checks failed before fixes; all 11 editor tests pass under Xvfb
   at 1920×1080/96 DPI. The pure bitmap probe also passes with display variables
   removed. The extension prerequisite and `git diff --check` pass. The frozen
   audit, working app/default font XML and preview PNG retain their prior hashes.

## Boundaries

This batch establishes three narrow correctness guarantees. The general policy
for applying rendering changes to hand edits, undo/dirty-document lifecycle,
legacy-file migration, other import/export bugs, batch output geometry, color
restoration and embedded editor layout remain separate work. Deployment and
emulator code are outside this contract. `.font` is a monochrome export: exact
pixel comparisons use the configured threshold result, not preservation of
arbitrary source colors or alpha.

The broader cleanup order discussed with the author remains a recommendation:
document integrity, deterministic import/export corrections, then deployment
helper corrections. Promote any later batch into the root TODO before starting
it; this contract does not silently authorize all 26 audit findings.
