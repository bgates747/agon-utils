# UI-005 — Embed character editing in the main application

Status: **Requested direction — implementation deferred.**
Created: 2026-09-10.
Tracking: [Font Editor TODO](../../TODO.md).

The author confirmed character editing works again, then clarified that the
editor belongs inside the main application, not in a separate top-level window.
The current popup is a functioning interim implementation. No code changes are
authorized as part of the current audit.

The [application audit](../application-audit-2026-09-10.md) records document
ownership and edit-loss issues in F01/F04, and the proposed UI/model boundaries.
Embedding must not hide or compound those lifecycle problems.

1. [ ] Choose an embedded pane layout that keeps the atlas and selected character
   visible and usable with large UI sizes and atlas zoom.
2. [ ] Route selection and pixel editing through that pane while preserving
   glyph switching, export behavior, scrolling, and responsive interaction.
3. [ ] Remove the separate character-window lifecycle and update its integration
   tests and documented behavior when implementation is authorized.
