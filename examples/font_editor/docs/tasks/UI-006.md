# UI-006 — Restore the complete color-picking workflow

Status: **Requested eventual restoration — implementation deferred.**
Created: 2026-09-10.
Tracking: [Font Editor TODO](../../TODO.md).

The author wants the color-picking features reinstated. They were disabled or
left incomplete because earlier debugging did not resolve their failures; their
absence is not a product decision to remove color support. The audit must map
the existing capabilities and their blockers without modifying code.

The [application audit](../application-audit-2026-09-10.md) maps current blockers
in F06/F07 and F13–F15: missing native APIs, a failed constructor retaining an
input grab, alpha/return-contract mismatches, and stale picker image state.

1. [ ] Restore palette selection, hue/color pickers, selection highlighting,
   foreground/background updates, and cancellation/initial-color behavior.
2. [ ] Resolve the native API mismatches and connect color changes consistently
   to preview, pixel editing, and the supported color export paths.
3. [ ] Define alpha/transparency behavior and validate picker coordinates and
   layout under the accepted UI scaling and embedded-editor design.
4. [ ] Add integration coverage before considering color support restored.
