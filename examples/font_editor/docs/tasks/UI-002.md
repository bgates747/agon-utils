# UI-002 — Reconsider automatic desktop/per-monitor UI scaling

Status: **Deferred — reconsider only at the author's request.**
Created: 2026-09-10.
Tracking: [Font Editor TODO](../../TODO.md).
Origin: option 3 of [UI-001](UI-001.md).

The author accepted the persistent application UI-size preference in UI-001 and
asked to retain later options in case they change their mind. No implementation
of this alternative is currently authorized. The accepted behavior remains
[UI scaling](../ui-scaling.md).

## Work to consider if reactivated

1. [ ] Compare Tk's version, windowing system, reported DPI, and scaling with
   the desktop's configured display scale; identify a reliable startup source.
2. [ ] Choose a startup scale with a manual override and documented fallback
   when desktop information is unavailable. Avoid applying compositor scaling
   a second time.
3. [ ] Define and validate behavior for differently scaled monitors and moving
   the window between them. Per-monitor adaptation is not currently promised.
4. [ ] Verify readable controls and dialogs without changing atlas pixels or
   exported font sizing, then obtain author visual acceptance.

The rejected COSMIC-setting trial remains recorded in UI-001 and its development
log as historical context. It is not the current solution.
