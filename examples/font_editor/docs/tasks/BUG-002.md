authorized repair through the ongoing bug-fix workflow. The `.font` codec is
monochrome; storing a different raster-type label on those bytes cannot retain
gray levels. The quantized rendering option itself currently has no handler.

   grayscale conversion without a display.
2. [x] Default non-threshold saves to PNG, preserving the current atlas and
   raster choice in a normalized sidecar. Retain clearly labeled monochrome
   `.font` export as an explicit format choice.
   PNG export keeps pixels and raster settings in a normalized sidecar without
   changing the live configuration. Monochrome export retains its correct format.
3. [x] Honor the save dialog's selected format for extensionless filenames;
   preserve explicit supported extensions. PNG and its XML sidecar must reopen
   with the saved glyph geometry and pixels, including partial rows and edits.
   Verified raw PNG and XML opens, 18 glyphs in seven columns, a one-glyph range,
   preserved gray-level edits, uppercase extensions and cancellation. An actual
   Tk save dialog verifies switching from PNG to monochrome uses `.font`.
4. [x] Reproduce failures before fixing them, run headless regressions alongside
   the existing suite, and update the specification and dated log. Preserve the
   frozen audit, existing user assets/preferences and uncommitted work.
   Three initial tests failed before repair. A fourth caught and verified the
   correction for Tk's fixed-default-extension behavior. All 15 editor tests
   pass under Xvfb; the extension prerequisite and `git diff --check` pass.
