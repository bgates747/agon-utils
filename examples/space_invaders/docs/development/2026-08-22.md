# Development Log — 2026-08-22

## Source extraction

Established the extraction-only subproject from David Levy’s complete ASMX
reconstruction published by Computer Archeology. Preserved the file unchanged,
recorded its SHA-256, and added a provisional ASMX build description. The
actual port toolchain was subsequently clarified as agondev.

## Initial target decisions

Accepted agondev as the target assembler and eZ80 `ADL=0` as the application
execution mode. Recorded the decision in ADR-0001. The MOS application
boundary, low-address layout, and mixed-mode hardware adapters remain open
implementation work.

## Display investigation

Confirmed that complete UART streaming cannot carry the 7,168-byte original
framebuffer at 60 Hz. A resident VDP bitmap with sparse deltas remains a
candidate.

Inspected EZ80 Framebuffer Agon and its upstream vga-ez80 driver as read-only
references. The driver provides direct RGB332 framebuffer scanout and a
320×240 60 Hz 15 kHz mode, avoiding UART pixel bandwidth. The original packed
1-bit framebuffer therefore needs presentation conversion or a more invasive
scanout design. The full mode consumes most CPU time and owns Timer 1, so CPU
margin and split-interrupt integration require measurement. No display backend
was accepted during this investigation.

## SETUP-001 completed — agondev build baseline

Inventoried the installed agondev 1.0 toolchain at checkout
`b67ab2444a63267a42193f204889d466765d8dd2` (`nightly`) with GNU binutils
2.45. A direct assembly probe established that agondev's GNU assembler cannot
consume the preserved ASMX directive and Intel 8080 mnemonic dialect; it
reported 1,346 errors. Accepted a separate checked-in GNU Z80/eZ80 syntax
layer under `src/agon/` and left `src/invaders.asm` checksum-identical.

Replaced the provisional extraction build with an agondev assembler/linker
pipeline and a custom zero-based `ADL=0` linker script. The resulting MOS
probe places its name field at `0x04`, header at `0x40`, entry at `0x45`, sets
the short-mode stack to `0xfffe`, returns zero in `HL`, and crosses back to the
ADL caller with `RET.LIS`. The normal build emits a binary, object, listing,
and map and validates their critical layout and bytes.
