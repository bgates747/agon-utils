# Project Tasks

This directory contains the tracked detail record for every item in
`TODO.md`. Task files own scope, instructions, state, dependencies, decisions,
research, gotchas, and validation gates; `TODO.md` remains the authoritative
task index.

Keep machine-local bench inventory, filesystem topology, unique device
identifiers, and transient deployment paths out of tracked tasks. Put those in
the ignored project-root `HARDWARE.local.md` when needed.
