# Architecture Decision Records

ADRs preserve accepted Space Invaders port architecture and rationale. Open
questions and actionable work remain in `TODO.md` and the corresponding task
files under `docs/tasks/`.

Every ADR begins with:

```markdown
- Status: Proposed | Accepted | Rejected | Superseded
- Completeness: Partial | Complete
- Date: YYYY-MM-DD
- Related task: TASK-ID
```

A partial ADR must also identify its authoritative open-decision tracker.
Status describes whether recorded decisions are authoritative; completeness
describes whether known decisions remain unresolved within the ADR’s scope.
Qualification and implementation state do not alter either field.
